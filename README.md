# Netflix Recommendation System

## Overview

This project analyzes Netflix content and builds a content-based recommendation system using Machine Learning.

## Features

* Data Cleaning
* Exploratory Data Analysis (EDA)
* TF-IDF Vectorization
* Cosine Similarity
* Content-Based Recommendations

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

Netflix Titles Dataset (8800+ titles)

## Sample Recommendation

Input:
Kota Factory

Output:

* Yeh Meri Family
* Girls Hostel
* Betaal
* Engineering Girls
* Chaman Bahaar
